# Claude Claude Custom Auth

Testing the usage of the `apiKeyHelper` to send custom auth to LiteLLM.

Allows you to send a custom API key without needing to use Virtual keys to authenticate with LiteLLM.

## Details

1. LiteLLM locally with mock LLM
2. Claude Code CLI
3. Custom `.claude` config to enable `apiKeyHelper`
4. `apiKeyHelper.sh` which logs a fake key to the stdout

## Setup

1. Install Claude Code

```sh
npm install -g @anthropic-ai/claude-code
```

2. Run LiteLLM

```sh
docker compose up -d
```

3. Link the `apiKeyHelper.sh` and `settings.json` for Claude Code

```sh
ln ./apiKeyHelper.sh ~/.claude/apiKeyHelper.sh
ln ./settings.json ~/.claude/settings.json
```

## LiteLLM Config

Simple config just has a mock model to test responses and specifies the custom auth method.

The `custom_auth.py` is also very basic, just decodes the JWT and uses it's attributes to construct the `UserAPIKeyAuth` object..

This value is generated by the `apiKeyHelper.sh` which simply uses the `jwt` command (`brew install jwt-cli`) to create the JWT.
